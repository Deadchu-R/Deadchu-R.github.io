Why KesherAI

One home instead of five apps

Running AI locally today means LM Studio for chat, ComfyUI for images, another tool for speech and a CLI for coding agents — each with its own models folder. KesherAI ("connection" in Hebrew) connects them.

🖥️

Local first

Everything works offline, with no account. Built-in llama.cpp and stable-diffusion.cpp, downloaded for your GPU (CUDA, Vulkan or Metal). Cloud APIs are optional.

⚡

“Set it up for me”

Picks models that fit your computer, downloads them from Hugging Face with checksums, and rates every model good / OK / slow / too big for your hardware.

🤖

Coding agent

Works in a project folder — reads, searches, edits and runs commands, with permission modes, diffs, undo, and approvals from your phone or watch.

🎨

Images, video, music, 3D

Image generation and an image editor, plus a ComfyUI node page with ready-made flows: video (Wan), music from words, 3D objects from a picture.

📱

Your computer, in your pocket

Android app and installable web app: pair with a QR code, chat with your home computer from anywhere, wake it from sleep, approve actions.

🔌

Connect, don't reinvent

Uses LM Studio, Ollama, ComfyUI or any OpenAI-compatible server you already run — and exposes its own OpenAI-compatible API for your other tools.

🧩

Plugins, skills, MCP

A documented plugin API (new providers, categories and tools), SKILL.md skills, MCP, personas and a plugin store — built to be forked.

🎮

For game developers

The KesherAI Bridge plugin for Unreal Engine: pick a Blueprint and change it in words, with a live connection to the editor.

Download

Get KesherAI

Free forever. The newest version is picked automatically from GitHub releases.

🪟WindowsInstaller (.exe) 🍎macOSApple Silicon (.dmg) 🐧LinuxAppImage · .deb 🤖AndroidPhone app (.apk) — connects to your computer

Windows may show a SmartScreen warning because the installer isn't code-signed yet — choose “More info” → “Run anyway”. All releases and checksums: GitHub releases.

Or run it from source

git clone https://github.com/Deadchu-R/KesherAI.git
cd KesherAI
pnpm install
pnpm build:packages
pnpm dev     # core server on :7420 + UI on http://localhost:5173

Needs Node.js 22+ and pnpm 10+. On Windows, just double-click KesherAI.cmd.
