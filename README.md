# Roee Tal — Portfolio

Static site, no build step. Hosted free on GitHub Pages.

- Edit projects: the `PROJECTS` and `LAB` arrays near the bottom of `index.html`.
- Media is loaded from Google Drive by file ID (folder must be shared "Anyone with the link → Viewer").
- Put your CV next to `index.html` as `Roee-Tal-CV.pdf`.
